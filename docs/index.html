Install

Drag Beagle to Applications. The build is ad-hoc signed rather than notarized, so macOS will say it “could not verify Beagle is free of malware” — that is the missing notarization, not a finding. 

xattr -dr com.apple.quarantine /Applications/Beagle.app

Or: System Settings → Privacy & Security → Open Anyway.
